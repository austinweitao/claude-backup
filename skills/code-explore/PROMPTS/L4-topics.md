# L4: 专题深挖分析 Prompt

## 任务
分析 `{repo_path}` 的专题: `{topic_name}`

## 专题类型
| ID | 专题 | 分析重点 |
|----|------|----------|
| 1 | concurrency | 锁类型、竞态模式、死锁风险 |
| 2 | memory | 分配器、缓存、OOM 处理 |
| 3 | security | 权限检查、Sandbox、攻击面 |
| 4 | error | 错误传播、恢复、重试 |
| 5 | performance | 热点、延迟、优化点 |
| 6 | versioning | API 变更、兼容性、迁移 |

## 分析要求

### 专题 1: 并发与同步
- 锁类型统计 (spinlock/mutex/rwlock)
- 竞态条件识别 (共享状态访问)
- 死锁可能性分析
- 等待队列使用

### 专题 2: 内存管理
- 内存分配模式
- 缓存机制 (slab/slub)
- 内存泄漏检测点
- OOM 处理流程

### 专题 3: 安全与权限
- UID/SELinux 检查点
- FD 传递安全
- 输入验证
- 已知漏洞模式

### 专题 4: 错误处理
- 错误码定义
- 错误传播路径
- 超时/重试机制
- 资源清理

### 专题 5: 性能瓶颈
- 热点函数识别
- 延迟分布分析
- 锁竞争热点
- 优化建议

### 专题 6: 版本演进
- API 变更历史
- 兼容性处理
- 废弃警告
- 迁移指南

## 输出格式
- 专题分析报告
- 问题清单 (如适用)
- 优化/修复建议
